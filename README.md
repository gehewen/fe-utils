# fe-utils

> Curated frontend algorithm utilities in TypeScript, ported from [算法101](https://example.com).

A zero-dependency, tree-shakeable, dual ESM/CJS library providing 27 carefully selected algorithm functions across 5 namespaces — built for everyday frontend work and interview prep.

## ✨ Features

- **Pure functions**, no surprises — most operations return new values rather than mutating inputs.
- **Universal** — runs in modern browsers, Node.js ≥ 18, and bundlers.
- **Tree-shakeable** — import only the namespaces or functions you need.
- **Strictly typed** — full TypeScript with `noUncheckedIndexedAccess` for safer code.
- **Well-tested** — 90%+ coverage with Vitest.

## 📦 Install

```bash
pnpm add fe-utils
# or
npm install fe-utils
```

## 🚀 Usage

### Full namespace import

```ts
import { algo } from 'fe-utils';

algo.string.reverse('hello');        // 'olleh'
algo.array.containsDuplicate([1, 1]); // true
algo.array.mergeIntervals([[1,3],[2,6],[8,10],[15,18]]); // [[1,6],[8,10],[15,18]]
```

### Subpath import (smaller bundle)

```ts
import { string, array } from 'fe-utils/string';
import { mergeIntervals } from 'fe-utils/array';
```

### CJS

```js
const { algo } = require('fe-utils');
algo.string.reverse('hello');
```

## 📚 API

| Namespace | Functions | Description |
|---|---|---|
| `algo.string` | 7 | Reversal, palindromes, anagrams, substring search |
| `algo.array` | 11 | Rotation, dedup, intersection, merging, top-K |
| `algo.number` | 5 | Parsing, big integer, bitwise, calendars |
| `algo.math` | 2 | Integer reversal, Roman numerals |
| `algo.dp` | 2 | Maximum subarray, climbing stairs |
